# Лабораторна робота №5

## Проєктування системи класів у JavaScript

**Дисципліна:** WEB-програмування  
**Проєкт:** «Акустична варта»

### 1. Тема роботи

Проєктування системи класів у JavaScript на прикладі навчального вебпроєкту «Акустична варта».

### 2. Мета роботи

Навчитися переходити від набору окремих об’єктів і функцій до системи взаємопов’язаних класів, визначати їхні властивості та методи, використовувати композицію, наслідування та інтегрувати об’єктну модель у вебпроєкт.

### 3. Опис виконаної роботи

У межах лабораторної роботи було продовжено розробку вебпроєкту «Акустична варта», створеного в попередніх лабораторних роботах.

JavaScript-частину проєкту організовано за допомогою класів і модулів. Для цього створено такі компоненти:

- **NoiseSensor** — клас, який моделює датчик шуму, зберігає його ідентифікатор, рівень шуму та вимірювання.
- **NoiseMeasurement** — клас для представлення окремого вимірювання рівня шуму та часу його отримання.
- **MonitoringSystem** — клас для керування колекцією датчиків, пошуку та аналізу показників.
- **app.js** — головний файл для ініціалізації системи та взаємодії з вебсторінкою.

### 4. Основні можливості системи

У системі передбачено:

- створення об'єктів датчиків шуму;
- перевірку коректності показників;
- визначення статусу датчика;
- оновлення рівня шуму;
- додавання нових вимірювань;
- пошук датчика за ідентифікатором;
- фільтрацію датчиків;
- визначення критичних датчиків;
- обчислення середнього рівня шуму.

### 5. Класифікація рівня шуму

Для визначення стану датчиків використовуються такі межі:

| Рівень шуму               | Статус   |
| ------------------------- | -------- |
| До 55 dB включно          | normal   |
| Понад 55 до 70 dB включно | warning  |
| Понад 70 dB               | critical |

Межі класифікації використовуються як єдине бізнес-правило системи.

### 8. Перевірка роботи

Для перевірки синтаксису JavaScript було використано команди:

```bash
node --check js/app.js
node --check js/models/NoiseMeasurement.js
node --check js/models/NoiseSensor.js
node --check js/services/MonitoringSystem.js
```

Усі команди виконалися без повідомлень про синтаксичні помилки.

Для запуску вебсторінки використовується розширення Live Server у Visual Studio Code.

### 9. Висновок

Під час виконання лабораторної роботи було опрацьовано принципи об'єктноорієнтованого програмування в JavaScript. Створено класи для моделювання датчиків шуму, вимірювань та системи моніторингу. Розглянуто організацію взаємодії між об'єктами, використання методів, модулів та композиції.

У результаті роботи вдосконалено структуру JavaScript-коду навчального вебпроєкту «Акустична варта» та закріплено практичні навички проєктування класів.
